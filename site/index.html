Peitho Studio
Features Download GitHub

A desktop editor for Peitho decks.

Your deck stays a plain Markdown file. Studio adds the slide list, the editor and a live preview.

Download GitHub

Free · MIT · macOS, Windows, Linux (Tauri)

Features

  • Plain Markdown, always Edit the same file with any tool. Studio reloads.
  • Preview by the real engine peitho-core runs in-process. PC or phone canvas.
  • Drag, cut, paste slides Reorder, relayout, flag as Draft or Skip.
  • Sections with a time budget Name, minutes, collapse. Rehearse against it.
  • CodeMirror 6, vim optional Speaker notes. Undo and redo in the Edit menu.
  • Variants and languages Switch deck variants. UI in English and Japanese.

Build from source

Bun, Rust, and the Tauri v2 prerequisites.

git clone https://github.com/piconic-ai/peitho-studio
cd peitho-studio
bun install
bunx tauri build   # installers in src-tauri/target/release/bundle/
