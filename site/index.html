Peitho Studio
Download Peitho GitHub

A desktop editor for Peitho decks.

The Markdown file stays the source of truth.

Tour

Pillars

  • Markdown in, Markdown out No project file, no export step. Edit the same deck from any other editor; Studio watches it and merges the change.
  • Preview by peitho-core itself The engine runs in-process, so thumbnails and preview match peitho present. Flip the canvas to a phone.
  • Slides you can grab Drag to reorder. Cut, paste, change layout, mark as Draft or Skip. Layout mismatches are errors, not broken slides.
  • Sections with a time budget Name, minutes, collapse. Rehearsal mode times each section against the plan.
  • An editor for the keyboard CodeMirror 6 with an optional vim mode. Undo and redo span text and slide operations.

Download

  • Latest release github.com/piconic-ai/peitho-studio/releases

The Present button runs the peitho CLI:

brew install mizzy/tap/peitho
Build from source 
git clone https://github.com/piconic-ai/peitho-studio
cd peitho-studio
bun install
bunx tauri build

Needs Bun, Rust and the Tauri v2 prerequisites.
