Edit Peitho decks in a window.

Slides, editor and live preview around one Markdown file. The file stays yours.

Download Source

Features

  • Plain MarkdownEdit the deck from any tool. Studio picks up the change.
  • The real rendererpeitho-core runs inside the app. Preview as PC or phone.
  • Hands-on slidesDrag, cut, paste, relayout. Mark as Draft or Skip.
  • Timed sectionsSet minutes per section, then rehearse against them.
  • Keyboard editorCodeMirror 6, optional vim, one undo for everything.
  • VariantsSwitch language versions of a deck. UI in English and Japanese.

Present needs the peitho CLI.

brew install mizzy/tap/peitho
Build from source 
git clone https://github.com/piconic-ai/peitho-studio
cd peitho-studio && bun install
bunx tauri build

Needs Bun, Rust and the Tauri v2 prerequisites.
