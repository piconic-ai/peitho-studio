A desktop editor for Peitho decks.

Peitho decks are plain Markdown. Peitho Studio puts a slide list, an editor and a live preview around that file — and leaves the file exactly as it was: Markdown, editable by any other tool at the same time.

Download View on GitHub

Built with Tauri v2 and BarefootJS. Developed on macOS; Tauri also builds for Windows and Linux. MIT licensed.

Features

The file stays the source of truth

A deck is one Peitho Markdown file in a folder. Studio watches it on disk: save from another editor, or let an agent rewrite it, and the change is merged into the open deck or the deck reloads. No project file, no export step.

Live preview by the real engine

peitho-core, the renderer behind the peitho CLI, is embedded in the app. Thumbnails and the preview are what peitho present will show. Switch the preview between a PC and a phone canvas.

Slides as things you can grab

Drag to reorder. Cut, copy, paste, delete, move up or down from a context menu. Change a slide's layout, with a structure check that reports a mismatch as an error instead of a broken slide. Flag a slide as Draft or Skip.

Sections with a time budget

Mark a slide as a section start, name the section and give it minutes and seconds. Collapse a section in the slide list. Rehearsal mode times each section as you present and saves it for comparison against the plan.

An editor that fits your hands

CodeMirror 6 for the slide body and the speaker notes, with an optional vim mode. Undo and redo are unified across text edits and slide operations and sit in the Edit menu, where a native app keeps them.

Variants, languages, windows

Switch between language variants of the same deck kept in one folder. Open several decks in several windows. The UI is available in English and Japanese, following the OS or a setting.

Presenting from Studio launches the peitho CLI, so install that too if you want the Present button. Editing and preview work without it.

Build from source

Needs Bun, a Rust toolchain, and the Tauri v2 prerequisites for your OS. peitho-core is pulled from the Peitho repository as a Cargo git dependency.

git clone https://github.com/piconic-ai/peitho-studio
cd peitho-studio
bun install
bunx tauri build      # installers land in src-tauri/target/release/bundle/
bunx tauri dev        # or run it from source
